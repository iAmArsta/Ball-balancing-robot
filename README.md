# Ball-balancing-robot

Here I've uploaded STL files, G-code, and code for my ball-balancing robot.
This project is still a work in progress. It needs to be coded. The current code moves the platform up and down and tilts it in a wave form.
An example code written by AI also exists. As of now, it can detect the balls' x,y coordinates relative to the camera.
As my computer got wiped a while after the design process, the STLs were reconstructed from the G-codes recovered from my printer.
